# DevOps — Révisions

Ce dépôt regroupe une série de **révisions pratiques DevOps** basées sur les notions, outils et ateliers abordés dans mon dépôt principal :

**DevOps 2024**  
[GitHub - bejaouibechir/Devops2024 · GitHub](https://github.com/bejaouibechir/devops2024)

L'objectif n'est pas de proposer un cours complet, mais plutôt un environnement permettant de **réviser rapidement les concepts essentiels**, de pratiquer les commandes importantes et de consolider les connaissances à travers des exercices courts et progressifs.
